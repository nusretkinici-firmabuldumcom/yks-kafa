## 🤖 N8N + GPT-4o Kurulum

### Hızlı Başlangıç

1. **N8N Hesabı Oluştur**
   - [n8n.cloud](https://n8n.cloud) → Ücretsiz hesap
   - 5,000 ücretsiz workflow execution/ay

2. **Workflow'ları İçe Aktar**
   - `n8n-workflows.json` dosyasını indir
   - N8N'de "Import from File"
   - Workflow'u aktif hale getir

3. **OpenAI API Key Ekle**
   - [platform.openai.com](https://platform.openai.com) → API Keys
   - $5 ücretsiz kredi
   - N8N Environment Variables'a ekle

4. **Platform'u Yapılandır**
   - `n8n-admin.html` sayfasını aç
   - N8N instance URL'ini gir
   - "Test Connection" ile kontrol et
   - Aktif hale getir!
